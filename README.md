## HOW THIS WAS MADE
this project was made with [https://blender.org](https://www.blender.org/)

# heres how to use this project :)
1. Go to https://github.com/F9Motion/Monitor and download all step files
2. Print this in 3d printer with **PETG** plastic
3. Install the laptop display and display driver inside
4. Assemble the case and monitor mount
